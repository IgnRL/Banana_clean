  What other repos and guides do: I looked at the Social Science Data Editors 
  README template, the Papers with Code checklist, Cornell's research-code 
  README guide, the World Bank template, and paper-companion repos such as
  metaamplicon-recipe and the Bioconductor F1000 workflow. They agree on a few
  things:
  - the paper citation at the top
  - where the data comes from, with accession numbers
  - exact software versions
  - the order to run the scripts in
  - a table linking every figure and table in the paper to the script that makes
    it
  - how to cite the work, and a license

  What the README covers:
  - The paper and its "under revision at Environmental Microbiome" status.
  - A summary of the study design: 5 treatments × 6 time points × 3 replicates.
  - The folder layout and what each script does.
  - A description of each file in 01_Raw_data/, and the SRA accession
    PRJNA1368706.
  - R 4.5.3, Bioconductor 3.22, and install commands for the packages.
  - The run order, including the 04 → 04b → 04c chain for differential
    abundance.
  - A table mapping Fig. 1–4, Fig. S1–S8 and Tables S1–S8 to their scripts and
    output files.
  - The processing steps done before this repo (lima, USEARCH, UNOISE3, SINTAX,
    DADA2), plus citation and contact details.

  The clone URL is https://github.com/FiBL/banana, because that's the address
  the revised manuscript now gives.

  1. R version in Methods: the manuscript says "R v3.3.2 (2016)", but DESeq2
     1.50.2 needs R 4.5. Your machine has R 4.5.3, so the Methods text is
     probably out of date.

  3. 16S taxonomy: Methods say 16S taxonomy came from SINTAX/SILVA. But
     04_DAA_16S.Rmd:53 loads taxonomy_16S_dada2.RDa, and no script in the repo
     creates that file.

     - 01_Introduction_16S.Rmd uses ../ paths, while every other script uses
       paths from the project root, so one knit setting can't run them all.
     - 05_Correlations_ITS.Rmd:170,171,285 uses 01_Raw_Data with a capital D.
       That works on a Mac but fails on Linux.
     - apeglm, which the 04_DAA scripts load, isn't installed on this machine.
  5. Fig. S8 file names: two of its panels are still saved under old names:
     Supplemetary_FigureS7_Actinobacteria.png and Figure_XB_trichoderma.png. The
     README explains the mapping, but renaming the outputs would make it
     cleaner.
  6. No license: the README says reuse needs permission until you add one.
     Common choices are MIT for code and CC-BY 4.0 for data.
